# TOP-C — The Other Playing Cards

Official site for TOP-C decks, the shop, and **Spread Love** early access.

## What’s in this repo

- Home, Shop, About, and Contact
- Online Games → Spread Love (passcode: `GLORY`)
- Product art and the playable Spread Love table (`public/spread-love/`)

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL printed in the terminal (port 8080).

## Put it on GitHub

1. Create a new repository (or use your existing `TOPC.github.io` repo).
2. Unzip this folder and push:

```bash
git init
git add .
git commit -m "TOP-C website"
git branch -M main
git remote add origin https://github.com/YOUR-USER/YOUR-REPO.git
git push -u origin main
```

This app is a Vite / TanStack Start site, not a plain HTML GitHub Pages dump. The easiest live host is [Vercel](https://vercel.com): Import the GitHub repo and deploy.

## Spread Love

Early Access is gated. The passcode is **GLORY**. It is asked every time someone opens the table.
